Platform FAQ

Which cloud region do we run in?

Production runs in AWS eu-west-1 on EKS.

Where do I find service dashboards?

Each service README links to its Grafana dashboards.

How do I get production access?

Request the prod-readonly role through the access portal; write access needs a manager approval.

Which services use Redis?

checkout-service (carts) and api-gateway (rate-limit counters).
