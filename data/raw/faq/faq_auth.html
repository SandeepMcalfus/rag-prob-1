Authentication FAQ

How are access tokens signed?

Access tokens are JWTs signed with HS256 using a shared secret distributed via Vault.

How long do access tokens last?

15 minutes. Refresh tokens last 7 days.

Which authentication mechanism does service-to-service traffic use?

Mutual TLS (mTLS), with OAuth2 client-credentials tokens for services that need caller identity.
